# Code of Conduct

Dieses Projekt erwartet eine sachliche, respektvolle und technisch nachvollziehbare Zusammenarbeit. Kritik an Code, Architektur oder Entscheidungen soll sich auf das Artefakt und seine Wirkung beziehen, nicht auf die Person.

Nicht akzeptiert werden insbesondere persönliche Angriffe, Belästigung, Veröffentlichung privater Informationen oder das Einstellen realer personenbezogener Bewerbungsdaten als Testmaterial.

Bei späterer Öffnung für externe Beiträge soll vor dem ersten Community-Release ein etablierter, vollständig dokumentierter Code of Conduct ausgewählt und versioniert werden.
